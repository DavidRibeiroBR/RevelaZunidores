Atomic Heart • Base Game + All DLCs

RevelaZunidores

Collectible finder for Atomic Heart (base game + DLCs). Shows where the collectibles of the current map are: Chirpers, talking corpses, Testing Ground crates, weapon blueprints, Limbo apples and coins, DLC4 statuettes, and more. English is the default language; Portuguese (Brazil) is built in.

Localizador de colecionáveis para Atomic Heart (jogo base + DLCs). Mostra onde estão os colecionáveis do mapa atual: Zunidores, cadáveres falantes, caixas de Polígonos, projetos de armas, maçãs e moedas do Limbo, estatuetas da DLC4 e muito mais.

Install

Instalação

All paths are relative to: Todos os caminhos são relativos a: AtomicHeart/Binaries/Win64/
  1. Install UE4SS in the game.
  2. Copy MemberVariableLayout.ini, UE4SS-settings.ini and the UE4SS_Signatures folder into the UE4SS folder (next to UE4SS.dll). If you keep your own settings file, set FExecVTableOffsetInLocalPlayer = 0x30.
  3. Copy the RevelaZunidores folder into UE4SS's Mods/ folder and enable it (mods.txt or an enabled.txt file inside the mod folder).
  4. Optional: install ReShade (add-on version) for the game and copy reshade_addon/RevelaZunidores.addon64 next to the game executable.
  5. Optional: open the menu with RevelaZunidores/menu/Abrir menu.bat.
  1. Instale o UE4SS no jogo.
  2. Copie MemberVariableLayout.ini, UE4SS-settings.ini e a pasta UE4SS_Signatures para a pasta do UE4SS (ao lado de UE4SS.dll). Se mantiver seu próprio arquivo de configurações, defina FExecVTableOffsetInLocalPlayer = 0x30.
  3. Copie a pasta RevelaZunidores para dentro de Mods/ do UE4SS e ative o mod (via mods.txt ou criando um arquivo enabled.txt na pasta do mod).
  4. Opcional: instale o ReShade (versão com suporte a add-ons) para o jogo e copie reshade_addon/RevelaZunidores.addon64 para a pasta do executável do jogo.
  5. Opcional: abra a janela de menu executando RevelaZunidores/menu/Abrir menu.bat.

Changelog

v1.0.1
  • Steam overlay (Shift+Tab) works again: the bundled UE4SS-settings.ini no longer opens the UE4SS debug window (GuiConsoleEnabled = 0), which took over the overlay.
  • Per-category marker limits: markers and compass are limited per category ("Max. markers per category"), so a category with many nearby items (Limbo apples) no longer hides the other checked categories.
  • Faster marker loading: markers show up seconds after loading a save — the mod repeats the full scan every 3 s while the level is still loading, instead of waiting 60 s.
  • Safe default distance: the ReShade add-on uses 500 m, never "no limit", when the mod does not send a category distance.
  • Overlay da Steam (Shift+Tab) funcionando novamente: o UE4SS-settings.ini incluso não abre mais a janela de debug do UE4SS (GuiConsoleEnabled = 0), que tomava foco do overlay.
  • Limite de marcadores por categoria: marcadores e bússola são limitados por categoria ("Max. markers per category"), evitando que categorias com muitos itens próximos (maçãs do Limbo) ocultem outras categorias marcadas.
  • Carregamento mais rápido: os marcadores aparecem segundos após carregar um save — o mod repete a varredura completa a cada 3 s enquanto o nível carrega, em vez de esperar 60 s.
  • Distância padrão segura: o add-on do ReShade usa 500 m (nunca "sem limite") quando o mod não envia uma distância específica da categoria.
